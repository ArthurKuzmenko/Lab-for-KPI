# Історія промптів для ШІ (ai/prompts.md)
## Prompt 1: Консультація щодо синтаксису EARS
> "я накідав вимоги для системи оренди авто, перевір чи правильно розставив ключові слова EARS по типу WHEN, WHILE, WHERE, IF. Також подивись формулювання в REQ-01...REQ-06 і скажи чи є граматичні або логічні помилки."
## Prompt 2: Форматування User Stories та Gherkin
> "Допоможи мені з оформленням User Stories та Gherkin сценаріїв. я розписав US-01, US-02 та US-03 для клієнта та менеджера, скажи чи правильно вказані Given,When,Then і чи нормально прописані параметри по типу car_id та office_id."
## Prompt 3: Питання по Use Case та трасуванню
> "допоможи по діаграмі Use Case, якщо у мене оплата обов'язкова при бронюванні, а промокод вводиться за бажанням, чи точно це include для оплати і extend для промокоду? також ще перевір мою матрицю трасування N:M, чи нормально підсвітити REQ-06 як непокриту вимогу?"
## Prompt 4: Валідація ADR та файлу захисту
> "подивись ADR про межі сценаріїв та структуру файлу DEFENSE.md для лабки, чи все там відповідає вимогам і чи чітко розписані розбіжності та виправлені помилки?"
## Prompt 5: Вирішення проблем з рендерингом діаграми на GitHub та перехід на PlantUML
> "я хотів зробити Use Case діаграму через Mermaid, щоб там були класичні чоловічки для акторів та прямокутна межа системи, але GitHub видає 'Parse error' при використанні спец синтаксису (стрілок наслідування `<|--` між акторами), одногрупник показав свою діаграму, як мені зробити схожу діаграму без проблем на гітхабі?
