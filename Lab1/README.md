# Лабораторна робота 1: Домен і модель даних (ER)
## Предметна область:система оренди автомобілів (car rental system)
Цей репозиторій містить модель даних для системи оренди автомобілів, специфікацію сутностей, обґрунтування нормалізації (ADR) та фіксований слід роботи з ШІ.
### Структура проекту:
- `spec.md`-текстова специфікація сутностей, атрибутів, ключів та Mermaid ER-діаграма.
- `adr/0001-domain-normalization.md`- Architecture Decision Record щодо нормалізації (3NF).
- `ai/prompts.md`- історія запитів до ШІ та проведений аудит розбіжностей.
- `DEFENSE.md`- документ для захисту роботи.
